Section 5: Component 3 & 5 — Tools, Skills, and Built-ins

Universal primitives (Tools) vs team-encoded knowledge (Skills) bound by a Registry.

🛠️ Universal Tools (Primitives)
Stateless, executable code handlers. Built using standard library packages for maximum portability.
view_file write_file run_bash grep_search
📚 Encoded Skills (Knowledge)
Markdown-formatted instruction files. Encodes team procedures on how to combine primitives.
git-rebase-flow test-runner-setup security-audit
💡 Built-in primitives should use Python stdlib only!
