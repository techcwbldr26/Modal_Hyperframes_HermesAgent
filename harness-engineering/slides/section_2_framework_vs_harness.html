Section 2: Framework vs. Harness

Understanding the distinction between building blocks for humans and pre-wired engines for agents.

FRAMEWORK
Assembly Required
  • 🧩 Provides primitives: Chains, state graphs, memory connectors, and vector retrievers.
  • 👨‍💻 Human assembles: The developer writes the control flow loop and connects the components.
  • ⚙️ Target: Built for human developers to assemble a specific application pipeline.
Examples:
LangChain · LangGraph · AutoGen · CrewAI
HARNESS
Pre-Wired Engine
  • 🚀 Ships complete: Loop, context manager, permissions, and tool registry already wired out-of-the-box.
  • 🎯 You supply goal: Developer gives a top-level prompt; harness handles execution autonomous turn-by-turn.
  • 🤖 Target: Built for the AI Agent to perform real work directly on workspaces.
Examples:
Claude Code · Cursor · Codex · Windsurf
🎯 Harness ships wired! You only provide the goal.
