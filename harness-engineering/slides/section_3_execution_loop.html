Section 3: Component 1 — The Execution Loop

A harness is fundamentally a while loop driving Read -> Act -> Observe -> Repeat.

def run_agent_loop(system_prompt, user_goal):
  messages = [{"role": "system", "content": system_prompt}]
  while iteration < max_iterations:
    # 1. READ & CALL MODEL
    response = llm.completion(messages)
    
    # 2. CHECK TERMINATION
    if not response.tool_calls:
      return response.text
    
    # 3. ACT (EXECUTE TOOL)
    result = execute_tool(response.tool_calls[0])
    
    # 4. OBSERVE (APPEND RESULT)
    messages.append({"role": "tool", "content": result})
Step 1: Read Read Prompt & History
Step 2: Act Model Generates Tool Call
Step 3: Execute Harness Runs Tool
Step 4: Observe Append Output to Context
🔄 Cycle repeats until final answer or max iterations reached.
🔁 The entire harness is built around this while loop!
